Quick Setup Guide

1
Prepare Your Repository
Create an empty GitHub repository dedicated to tracking your algorithmic coding solutions. This acts as your personal cloud-synced notebook.
2
Generate a Fine-Grained Access Token
Navigate to GitHub's Developer Settings → Personal Access Tokens → Fine-grained tokens. Select your target repository and ensure you grant exactly Read and Write access to the "Contents" permission scope.
3
Connect Your Data
Paste your generated Personal Access Token (PAT), exact GitHub username, and repository name into the secure configuration panel.

Data Maintenance

Refresh your local cache to instantly sync tags or reset your session data directly from GitHub.
